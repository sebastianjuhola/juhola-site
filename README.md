# juhola.org

Personal site of Sebastian Juhola. One static page, no build step.

- `index.html`: the whole page, styles included
- `assets/`: logo, photo, favicons, share image and self-hosted IBM Plex fonts (SIL Open Font License)
- `CNAME`: custom domain for GitHub Pages

Edit `index.html`, commit, push. GitHub Pages publishes the change within a minute.
